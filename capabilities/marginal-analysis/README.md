# Marginal Analysis

This capability uses an Excel model to analyze constrained optimization problems and determine the best decision based on the available resources and costs.

**Exercised in:** [Perfect Competition](../../docs/briefs/perfect-competition-brief.md) — I used this capability to find the most profitable planting mix while considering the farm's limited beds, labor costs, and diminishing returns. The [analysis](../../analysis/perfect-competition-analysis.md) and [recommendation memo](../../docs/decisions/perfect-competition-memo.md) explain my final results and the reasoning behind my recommendation.
